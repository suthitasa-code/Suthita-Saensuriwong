# KUSE Admission

### เว็บแอปพลิเคชันให้ข้อมูลการรับเข้าศึกษาในคณะวิทยาศาสตร์และวิศวกรรมศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตเฉลิมพระเกียรติ จังหวัดสกลนคร

## 1. เกี่ยวกับโครงงาน (About Project)

KUSE Admission เป็นเว็บแอปพลิเคชันที่พัฒนาขึ้นเพื่อรวบรวมและเผยแพร่ข้อมูลการรับสมัครเข้าศึกษาต่อของคณะวิทยาศาสตร์และวิศวกรรมศาสตร์ไว้ในเว็บไซต์เดียว ช่วยให้ผู้สนใจสามารถเข้าถึงข้อมูลประกาศรับสมัคร หลักสูตร กำหนดการ และเอกสารที่เกี่ยวข้องได้สะดวกยิ่งขึ้น พร้อมระบบจัดการข้อมูลสำหรับเจ้าหน้าที่ เพื่อให้สามารถปรับปรุงข้อมูลภายในเว็บไซต์ได้อย่างเป็นระบบ

## 2. ความสามารถของระบบ (System Features)

**2.1 เว็บไซต์สำหรับผู้ใช้งานทั่วไป (Public Website)**
- แสดงข้อมูลประกาศการรับสมัคร
- แสดงข้อมูลรอบการรับสมัคร TCAS และสถานะการรับสมัคร
- ค้นหาและกรองข้อมูลประกาศ
- แสดงรายละเอียดหลักสูตร
- แสดงแบนเนอร์ประชาสัมพันธ์
- ดูและดาวน์โหลดเอกสารประกอบการสมัคร
- รองรับการใช้งานบนคอมพิวเตอร์และโทรศัพท์มือถือ

**2.2 ระบบสำหรับผู้ดูแล (Admin Website)**
- เข้าสู่ระบบเพื่อจัดการข้อมูล
- จัดการประกาศรับสมัคร
- จัดการข้อมูลหลักสูตร
- จัดการแบนเนอร์ประชาสัมพันธ์
- จัดการเอกสารประกอบการสมัคร
- จัดการข้อมูลรอบ TCAS และตัวเลือกส่วนกลาง
- จัดการบัญชีและสิทธิ์ผู้ดูแลระบบ

## 4. โครงสร้างระบบ (System Architecture)

ระบบ KUSE Admission แบ่งออกเป็น 3 ส่วนหลัก เพื่อแยกหน้าที่การทำงานให้ชัดเจนและสะดวกต่อการพัฒนาและบำรุงรักษา

### 4.1 API (Backend)

ทำหน้าที่เป็นส่วนประมวลผลหลักของระบบ เชื่อมต่อกับฐานข้อมูล MySQL และให้บริการข้อมูลแก่ Frontend ผ่าน REST API โดยจัดการคำขอ ตรวจสอบข้อมูล ประมวลผล และส่งผลลัพธ์กลับในรูปแบบ JSON รวมถึงจัดการการเข้าสู่ระบบและตรวจสอบสิทธิ์ของผู้ดูแลระบบ

### 4.2 Frontend-kuse (Public Website)

เป็นส่วนติดต่อผู้ใช้งานทั่วไป พัฒนาด้วย React ทำหน้าที่แสดงข้อมูลประกาศ หลักสูตร ข่าวสาร แบนเนอร์ และเอกสารต่าง ๆ โดยดึงข้อมูลจาก API มาแสดงผล ผู้ใช้งานสามารถเข้าถึงข้อมูลได้โดยไม่ต้องเข้าสู่ระบบ และเน้นการเรียกดูข้อมูลเป็นหลัก

### 4.3 kuse-admission (Admin Website)

เป็นส่วนติดต่อสำหรับผู้ดูแลระบบ พัฒนาด้วย React ทำหน้าที่เป็นหน้าจัดการข้อมูลภายในเว็บไซต์ โดยเชื่อมต่อกับ API เพื่อเพิ่ม แก้ไข และจัดการข้อมูลต่าง ๆ ตามสิทธิ์ของผู้ใช้งาน มีการเข้าสู่ระบบและใช้ JWT สำหรับการยืนยันตัวตนในการเข้าถึงบริการที่ต้องได้รับอนุญาต

## 5. การติดตั้งและเริ่มต้นใช้งาน (Installation)

**สิ่งที่ต้องเตรียม**
- Node.js
- npm
- MySQL
- Git

**5.1 ดาวน์โหลดโปรเจกต์**

```bash
git clone <REPOSITORY_URL>
```

**5.2 ติดตั้ง Dependencies**

เข้าไปในแต่ละโฟลเดอร์ ได้แก่ `API`, `Frontend-kuse` และ `kuse-admission` แล้วรันคำสั่ง

```bash
npm install
```

**5.3 ตั้งค่าฐานข้อมูล**
- สร้างฐานข้อมูล MySQL
- นำเข้าไฟล์ `schema.sql` เพื่อสร้างตาราง
- นำเข้าไฟล์ `seed.sql` เพื่อเพิ่มข้อมูลเริ่มต้น (หากมี)
- ตั้งค่าการเชื่อมต่อฐานข้อมูลในไฟล์ `.env` ภายในโฟลเดอร์ API

**5.4 เริ่มต้นใช้งาน**

เปิด Terminal ในแต่ละโฟลเดอร์และรันคำสั่งตาม Scripts ที่กำหนดไว้ในไฟล์ `package.json`

## 6. การทำงานของระบบ (System Workflow)

ระบบแบ่งการทำงานออกเป็น 3 ส่วน ได้แก่ Backend, Public Website และ Admin Website โดย Frontend ติดต่อกับ Backend ผ่าน REST API เพื่อรับส่งข้อมูล Backend ประมวลผลคำขอและเชื่อมต่อกับฐานข้อมูล MySQL ก่อนส่งข้อมูลกลับในรูปแบบ JSON ส่วนระบบผู้ดูแลใช้ JWT สำหรับยืนยันตัวตนและตรวจสอบสิทธิ์ในการเข้าใช้งาน
